# docs/

- **`decisions/`** — registros de decisiones de arquitectura (ADRs). Cada vez que se
  elige una librería, una estructura o un enfoque no obvio, se documenta acá. Empezar
  por `0001-estructura-y-metodologia.md`; plantilla en `0000-adr-template.md`.
- **`hardware/`** — pinout, datasheets, notas de cableado y fotos del setup físico
  (ESP32 + módulos RF).
- **`captures/`** — capturas RF exportadas (timing crudo + notas de análisis), usadas
  como fixtures para el analizador de protocolos.
